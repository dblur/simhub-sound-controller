# App Volume Controller

Плагин для [SimHub](https://www.simhubdash.com/), который выносит громкость отдельных приложений на кнопки руля, кноп-бокса или любого другого устройства.

!([Интерфейс плагина](https://github.com/dblur/simhub-sound-controller/blob/main/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202026-11-02%20170652.png)
Игра остаётся на своей громкости. Яндекс Музыка, Spotify, браузер, Discord или голосовой чат получают собственные кнопки: тише, громче, пауза, без звука и переключение трека. Уровень громкости сразу виден на подсветке кнопок.

Автор: **dmitblur**.

## Установка

Нужны Windows, .NET Framework 4.8, установленный SimHub и [.NET SDK](https://dotnet.microsoft.com/download), чтобы собрать плагин.

Из папки проекта запустите `install.cmd` или в PowerShell:

```powershell
.\install.ps1
```

Скрипт собирает плагин и кладёт `User.AppVolumeController.dll` рядом с `SimHubWPF.exe`. Если SimHub в этот момент открыт и держит старый файл, установщик подменяет его сам. После этого SimHub нужно закрыть полностью, вместе со значком в трее, и открыть снова.

В левом меню появится пункт **«Громкость приложений»**.

Путь к SimHub по умолчанию — `C:\Program Files (x86)\SimHub\`. Другую папку можно указать переменной `SIMHUB_INSTALL_PATH`. Команда `dotnet build -c Release` вызывает тот же установщик.

## Как настроить

1. Добавьте канал и выберите приложение. У канала постоянный номер: если удалить средний, номера остальных не сдвигаются, и кнопки с подсветкой остаются на своих каналах. Каналов может быть до 16.
2. В блоке **«Кнопки устройства»** назначьте действия на кнопки.
3. В профиле подсветки добавьте эффект **«Громкость канала»**. **Start position** — с какого светодиода начать, **Led count** — сколько кнопок зажечь подряд. Одна кнопка — это 1, группа из четырёх — это 4.
4. Цвета задаются в карточке канала: громкость, без звука и пауза.

Карточку можно свернуть. Снаружи остаются номер, название и переключатель, остальное скрывается до следующего разворота.

## Кнопки

Громкость в Windows принадлежит процессу. Несколько окон одной программы используют одну и ту же громкость. Фильтр по заголовку помогает выбрать нужный процесс, когда имена совпадают.

| Кнопка | Что происходит |
| --- | --- |
| Громче / тише | Громкость меняется на заданный шаг: 1, 2, 5, 10, 25% или своё значение от 1 до 100 |
| Пауза | Короткое нажатие ставит воспроизведение на паузу или снимает её |
| Без звука | Удержание той же кнопки около полусекунды один раз переключает mute. Пока палец держит кнопку, команда больше не повторяется |
| Следующий / предыдущий трек | Одно нажатие отправляет приложению команду смены композиции |

Кнопка **«Без звука»** в карточке канала сразу переключает mute. Короткое нажатие и удержание относятся к кнопке устройства.

Пауза и треки уходят в сеанс воспроизведения выбранного приложения. Плагин узнаёт его и по имени процесса, и по папке программы, поэтому «Яндекс Музыка» не путается с браузером, который играл последним. Если приложение не опубликовало такой сеанс, команда отправляется его окну. Две вкладки одного браузера делят один сеанс: Windows не разделяет их.

Индикатор паузы ведёт сам плагин. После короткого нажатия он запоминает паузу. Когда приложение снова начинает звучать и не стоит на mute, индикатор гаснет.

## Подсветка

На 0% светодиод погашен. Выше нуля он уже светится выбранным цветом и к 100% доходит до полной яркости. Без звука и пауза горят своими цветами на полную яркость. Если включены оба состояния, цвет мигает между ними.

Закрытое приложение не подсвечивается. Кнопка загорается, когда это приложение хотя бы запущено, даже если оно сейчас молчит.

Тот же цвет доступен свойствами `LedR`, `LedG` и `LedB`, если хочется собрать свою формулу в редакторе эффектов.

## Свойства

`N` — номер на карточке канала.

| Свойство | Значение |
| --- | --- |
| `AppVolumePlugin.ChannelN.Volume` | Громкость, 0–100 |
| `AppVolumePlugin.ChannelN.Volume01` | Та же громкость, 0–1 |
| `AppVolumePlugin.ChannelN.Muted` | 1, если звук выключен |
| `AppVolumePlugin.ChannelN.Paused` | 1, если стоит пауза |
| `AppVolumePlugin.ChannelN.Peak` | Уровень сигнала, 0–100 |
| `AppVolumePlugin.ChannelN.Peak01` | Уровень сигнала, 0–1 |
| `AppVolumePlugin.ChannelN.IsRunning` | 1, если приложение открыто |
| `AppVolumePlugin.ChannelN.LedR` `LedG` `LedB` | Итоговый цвет подсветки |

События: `VolumeChanged`, `Muted`, `Unmuted`, `PlayPause`, `NextTrack`, `PreviousTrack`. Полное имя выглядит как `AppVolumePlugin.ChannelN.PlayPause`.
